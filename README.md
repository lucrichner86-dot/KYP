# KYP — Know Your Product

Know Your Product is to goods what Know Your Customer is to finance: a verifiable record of what a product is, where it came from and what happened to it, built on real supply chain data. The first use case is cannabis; other highly regulated goods follow.

**Status: research phase. Nothing is being built yet.**

| Path | What it is |
| --- | --- |
| `reports/` | Research reports. Start with the EU product passport analysis. |
| `research_notes/` | Source notes behind each report |
| `archive/` | The first build (November 2026), set aside. See `archive/README.md`. |
